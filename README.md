# 云AI智能翻页笔

2.兼音量调节功能

- **按键响应功能**  
1.一键接入云盘软件  
2.一键保存笔记

### 云盘功能
-  **云盘功能**  
1.文件基础上传下载预览功能  
2.文件夹同步功能  
3.云盘不限速

1.支持常见协议

2.接收器硬件-云盘-主机 三方绑定 保护数据安全

- **截图功能**  
1.一键截图  
2.笔记与几何画图功能集成  
- **保存功能**  
1.截图自动保存
- **发送功能**  
1.自动发送到自己云盘
