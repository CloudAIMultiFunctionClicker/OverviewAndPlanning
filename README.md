# 云笔

## 一、核心功能

### 1. 翻页与控制
- **基础翻页**  
  - 支持 PPT 等主流演示文档的上/下页控制（左/右键映射）
- **音量调节**  
  - 云笔本身有单独的音量调节（滚轮），避免频繁切出演示界面

### 2. 一键快捷操作
- **云盘**  
  - 短按指定键：快速唤起云盘客户端
- **保存笔记**  
  - 即时将当前屏幕标注/手写笔记保存至本地 + 同步云端

---

## 二、云端能力

### 1. 云盘核心功能
- **基础文件操作**  
  - 上传、下载、在线预览（支持文档/图片/音视频/PDF）
- **资源同步**  
  - 指定文件夹实时同步，断点续传，冲突自动标记，课件/资源跨设备随时保持最新状态

### 2. 兼容性
- **集成系统**  
  - 协议兼容：WebDAV、ftp 等主流标准访问
  - 可以将云盘集成到win文件资源管理器，拥有和win本地文件的相同使用体验

---

## 三、帐号

### 硬件协同
- **加密绑定**  
  - 翻页笔硬件唯一 ID + 用户云账号加密绑定，帐号随云笔随带随走  
- **信任链**  
  - 接收器 ↔ 云服务 ↔ 主机三端双向认证，设备断开连接就会失去访问权限
  - 未授权设备无法访问同步数据（即使物理接入）

---

## 四、智能笔记

### 1. 一键截图 + 标注
- **快捷触发**  
  - 自定义按键触发全屏/窗口/区域截图 ，之后可以编辑
- **集成标注工具**  
  - 支持：文本批注、箭头/高亮/几何图形（矩形/圆/直线）、马赛克遮盖  
  - 笔记手写同步（压感支持）

### 2. 笔记存发
- **自动保存**  
  - 截图默认存至 `~/CloudPen/Screenshots/` + 时间戳命名  
- **智能分发**  
  - 自动上传至个人云盘指定文件夹  
  - （计划）支持发送到其他设备（闺蜜机，或观看者手机）方便观看者查看演讲者的笔记

---

## 五、扩展与个性化

### 1. 基础配置
- **硬件设置界面**  
  - 电量/固件版本/连接状态/按键映射，翻页延迟、震动反馈开关、LED指示灯策略、休眠时长
- **软件设置项**  
- **（计划）拓展功能**
  - 允许用户添加拓展 并且可以把拓展加到悬浮窗

### 2. 自定义宏功能（高级功能）
- **按键宏编程**  
  - 支持将复杂操作绑定至单个实体键，例如：  
    - `Macro A` = `Win + Shift + S`（截图）→ 自动保存 → 上传云盘  
    - `Macro B` = `Alt + Tab` → `Ctrl + L` → 输入网址 → `Enter`（快速打开直播页）  
  - 支持录制/编辑宏脚本（JSON 格式导出备份）
